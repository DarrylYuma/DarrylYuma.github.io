Airbnb Seattle 2025 Quarterly Data Analysis

DATASET OVERVIEW

Official 2025 quarterly data of Airbnb listings for Seattle, USA. The dataset is comprised of the listings and calendar datasets and combined have a total of over 6900 listings and over 1,000,000 bookings. The metrics included in this dataset are room type, neigborhood group, price, number of bedrooms, bathrooms, and many more.

ANALYSIS

The dataset is first cleaned and then a dashboard is created that produced the following visualizations:

  • Price per Neighborhood Group:
    A bar chart with accompanying map chart that shows the average price for an Airbnb in every neigborhood in Seattle.
  • Revenue for Year:
    A line chart that shows revenue trend over the year. It can be concluded from the graph that sales drop off the most in February.
  • Price per Room Type:
    A bar chart that shows the average price for each room type.
  • Count of Room Types:
    A count displaying the number of each type of room listings in the selected neighborhood group.

SUMMARY

The dashboard can be interacted with to provide further insight into specific neighborhood groups by clicking on the bar chart. The dashboard created in this project can allow the user to easily sort and get information on where is the most suitable option to stay.
